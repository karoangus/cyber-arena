# نبرد سایبری — Cyber Arena 3D

شوتر اول‌شخص سه‌بعدی تحت وب (WebGL با Three.js + React + Vite) که هم روی **موبایل** (جوی‌استیک لمسی) و هم روی **دسکتاپ** (WASD + ماوس با Pointer Lock) اجرا می‌شود. پروژه به‌صورت یک **وب‌اپ پیشرونده (PWA)** آماده شده: قابل نصب روی صفحهٔ خانهٔ گوشی و دارای manifest، آیکون‌ها و Service Worker برای اجرای آفلاین پوستهٔ اپ.

نسخهٔ اصلی بازی که این مخزن از روی آن ساخته شده در `archive/original-game-source.zip` نگهداری می‌شود.

## شروع سریع

```bash
npm install
npm run dev        # سرور توسعه روی http://localhost:5173 (باز از بیرون هم قابل دسترسی است)
```

پیش‌نمایش زندهٔ همان سرور توسعه در محیط Arena به‌صورت خودکار نمایش داده می‌شود.

## بیلد تولید (وب‌اپ)

```bash
npm run build      # typecheck + باندل تک‌فایلی در dist/
npm run preview    # سرو بیلد تولید روی http://localhost:4173
```

خروجی `dist/` شامل `index.html` تک‌فایلی (کل بازی داخل یک فایل) به‌همراه `manifest.webmanifest`، `sw.js` و `icons/` است. همین پوشه را روی هر هاست استاتیک (Netlify، Vercel، GitHub Pages یا حتی یک فایل‌سرور ساده) بگذارید و بازی به‌عنوان وب‌اپ قابل نصب خواهد بود؛ در بیلد تولید Service Worker ثبت می‌شود و دکمهٔ «نصب روی گوشی / دسکتاپ» در منوی شروع ظاهر می‌شود (در صورت پشتیبانی مرورگر).

## دیپلوی (GitHub Pages)

بیلد تولیدی به‌صورت خودکار منتشر می‌شود (`.github/workflows/deploy-pages.yml`): هر push به `main` → typecheck + build → خروجی در پوشه‌ی `app/` **کامیت می‌شود** و همزمان به‌عنوان artifact برای Pages هم آپلود می‌شود.

چرا این‌طور؟ سایت فعلاً در حالت legacy (Deploy from branch) است و **ریشه‌ی مخزن** را سرو می‌کند. بنابراین:

- `index.html` ریشه یک «بوت‌استرپ» هوشمند است: در محیط توسعه (وقتی vite است) خودش بازی را از سورس اجرا می‌کند، و روی میزبانی استاتیک به‌صورت خودکار به بیلد آماده‌ی `./app/` پرش می‌کند.
- پوشه‌ی `app/` (خروجی بیلد تک‌فایلی) در مخزن کامیت می‌شود تا هم legacy Pages آن را سرو کند و هم بعد از اولین بازدید، سرویس‌ورکر آن را برای اجرای آفلاین کش کند.
- اگر روزی Settings → Pages → Source روی **GitHub Actions** بگذارده شود، artifact مستقیماً منتشر می‌شود و پرش `./app/` هم بی‌اثر می‌شود (خودکار؛ نیازی به تغییر کد نیست).

## آفلاین

بازی ۱۰۰٪ آفلاین اجرا می‌شود و **هیچ درخواستی به اینترنت ندارد**:

- فونت وزیرمتن به‌صورت لوکال در `src/assets/fonts` باندل می‌شود (بدون CDN گوگل).
- بیلد تولید تک‌فایلی است (کل بازی در `dist/index.html`).
- Service Worker کل پوسته را از پیش کش می‌کند (offline-first): بعد از اولین بازدید، بازی بدون اینترنت بالا می‌آید و نسخه‌های جدید در پس‌زمینه کش می‌شوند و در بازدید بعدی اعمال می‌شوند.
- نگهبان بوت (`index.html`) اگر مشکلی پیش بیاید وضعیت واقعی را نشان می‌دهد (آفلاین بودن دستگاه / کش خراب) و دکمه‌ی «پاک کردن کش و شروع دوباره» دارد.

## تست و بررسی

```bash
npm run typecheck  # tsc --noEmit
npm test           # دو سوئیت: logic + engine (اجرای کد واقعی shipped در Node)
```

- سوئیت `logic`: برخورد دایره، محدودسازی میدان، دید مستقیم و ذخیرهٔ تنظیمات.
- سوئیت `engine`: اجرای headless خودِ موتور (`src/game/engine.ts`) با WebGLRenderer تقلبی — حلقهٔ update، موج‌ها، هوش دشمن، شلیک، آیتم‌ها، مرگ/restart، ورودی کیبورد/ماوس و سناریوی localStorage بلاک‌شده، به‌علاوهٔ مکانیک‌های جدید:
  - **پول:** هر کیل ۱ دلار و باس ۱۰ دلار.
  - **باس:** `isBossWave` هر ۱۰ موج، صف اسپاون باس، جان/هوش مصنوعی باس، اجرای ۵ ثانیهٔ کامل هوش مصنوعی بدون خطا، اسلوموشن مرگ باس.
  - **شاپ:** فعال شدن بعد از پاک‌سازی موج باس با تایمر ۱۰۰ ثانیه، قیمت پلکانی آپگرید آسیب (۵/۱۰/۱۵) و سقف ۳ سطح، خرید خشاب ۵۰ تیری ۲ دلاری، خرید چاقو ۲۰ دلاری و باز شدن اسلات، رد شدن خرید بدون پول (`deny`) و بسته بودن شاپ بیرون وقفه.
  - **اسلات و ضربهٔ نزدیک:** تعویض اسلات، مصرف‌نشدن مهمات با دست خالی، آسیب رسیدن ضربهٔ دست/چاقو و قوی‌تر بودن چاقو از مشت.
  - **نشانه‌گیری:** افزایش `aimAmount`، زوم شدن FOV و بازگشت هر دو پس از رهاسازی.
  - **خشاب:** پر نشدن خودکار خشاب/مهمات در شروع موج بعد و کار کردن پرکردن دستی.
  - **مدل اول‌شخص (`src/game/viewmodel.ts`):** ۴۰۰ فریم انیمیشن در همهٔ حالت‌ها (راه‌رفتن، دویدن، نشانه، ریلود، ضربه، تعویض اسلات، مرگ) بدون هیچ NaN/تبدیل نامعتبر.

> نکته: در این محیط sandbox مرورگر و GPU در دسترس نبود؛ بنابراین رفتار رندر/WebGL در مرورگر واقعی با کلیک روی پیش‌نمایش زنده بررسی شود. `npm test` مسیرهای منطقی و رفتاری موتور را با اجرای خودِ کد shipped تأیید می‌کند.

## عیب‌یابی لود نشدن بازی

اگر به‌جای بازی پیام خطا دیدی:

1. **«دستگاه آفلاین است»** یعنی اینترنت وصل نیست و هنوز اولین بارگذاری انجام نشده. برای بار اول یک‌بار اینترنت را وصل کن و بازی را باز کن؛ از آن به بعد بازی کامل آفلاین اجرا می‌شود.
2. **«بازی لود نشد» / «لود بازی طول کشید»** (وقتی اینترنت وصل است) یعنی کش قدیمیِ نسخه‌ی قبلی سایت خراب مانده — دکمه‌ی «پاک کردن کش و شروع دوباره» را بزن تا سرویس‌ورکر و کش پاک و صفحه تازه لود شود.
3. **«گرافیک بازی لود نشد»** یعنی WebGL در دسترس نیست — شتاب سخت‌افزاری (Hardware Acceleration) را در تنظیمات مرورگر فعال کن، از Chrome/Safari به‌روز استفاده کن و مطمئن شو JavaScript فعال است.
4. اگر از نسخهٔ نصب‌شده (PWA) استفاده می‌کنی و بعد از آپدیت مشکل داری، یک‌بار اپ را حذف و دوباره نصب کن تا Service Worker قدیمی پاک شود.

## گیم‌پلی

- **موج‌ها و باس‌فایت:** هر ۱۰ موج یک **نبرد باس** است (باس با جان زیاد، رگبار ۵ تایی، انفجار حلقه‌ای ۱۲ تایی، یورش با خیزِ قابل‌فرار، ضربهٔ زمینی و احضار نیروی کمکی). زیر ۵۰٪ جان **خشمگین** می‌شود (سریع‌تر و تهاجمی‌تر). نوار جان باس بالای صفحه و نشان باس روی رادار است.
- **پول و شاپ:** هر کیل **۱ دلار** و هر باس **۱۰ دلار**. بعد از شکست باس، **شاپ ۱۰۰ ثانیه** باز می‌شود (دکمهٔ 🛒 در HUD فعال و تایمر شمارش معکوس موج بعد نمایش داده می‌شود؛ با باز کردن شاپ بازی و تایمر متوقف می‌شود).
  - **آپگرید آسیب اسلحه:** ۵ دلار، بعد از هر خرید ۵ دلار گران‌تر (۵ → ۱۰ → ۱۵) و حداکثر **۳ بار** (هر سطح +۳۰٪ آسیب).
  - **خشاب:** هر **۵۰ تیر ۲ دلار**.
  - **چاقو:** **۲۰ دلار** — اسلات سوم باز می‌شود؛ آسیبش کمی از دست خالی بیشتر است (۲۶ در برابر ۲۰) و سریع‌تر/دوربردتر می‌زند.
- **اسلات‌ها:** بین **دست خالی ✊ / اسلحه 🔫 / چاقو 🔪** جابه‌جا شو. ضربهٔ نزدیک مهمات نمی‌خواهد ولی باید به دشمن بچسبی ⇒ پرریسک (با این حال گلوله‌های دشمن را هم برمی‌گرداند). ضربهٔ نزدیک فقط دستی است (شلیک خودکار روی آن فعال نمی‌شود).
- **خشاب خودکار پر نمی‌شود:** شروع موج بعد فقط آیتم روی زمین می‌اندازد؛ برای پر کردن خشاب باید خودت **R** (یا دکمهٔ «خشاب») را بزنی. اگر مهمات ذخیره تمام شود، اسلات دست/چاقو تنها راه است تا از شاپ خشاب بخری.
- **نشانه‌گیری (ADS):** نگه‌داشتن نشانه = زوم، پراکندگی تقریباً صفر، حساسیت کمتر و سرعت حرکت کمتر (دقت در برابر سرعت). مگسک اسلحه دقیقاً وسط دید می‌نشیند و نقطهٔ نشانه روشن می‌شود.
- **انیمیشن و حرکت بازیکن:** مدل اول‌شخص کامل (بازو، دستکش، اسلحه، چاقو، مشت) با انیمیشن‌های مجزا برای بی‌حرکتی، راه‌رفتن، دویدن (حالت حمل اسلحه)، شلیک (لگد + فلش دهانه)، پرکردن خشاب (بیرون کشیدن خشاب، خشاب تازه، گلنگدن)، نشانه‌گیری، مشت/برش چاقو و تعویض اسلات؛ به‌علاوه صدای قدم، تکان دوربین با هر گام، فرود سنگین بعد از پرش، خم شدن دوربین هنگام جابه‌جایی عرضی و اسلوموشن هنگام انفجار باس.

# Cyber Arena 3D (English)

A 3D first-person wave shooter that runs fully in the browser (Three.js + React + Vite), playable on mobile (touch joysticks) and desktop (WASD + pointer-lock mouse). Packaged as an installable PWA with manifest, icons and an offline-capable service worker.

- Dev: `npm install && npm run dev`
- Production build (single-file app + PWA assets in `dist/`): `npm run build && npm run preview`
- Checks: `npm run typecheck`, `npm test`
- The original source zip is kept at `archive/original-game-source.zip`.
